# ⚔️ AI-Generated Fantasy RPG Site

This project is a full-scale fantasy RPG website created entirely using **Claude AI**. 

## 🤖 About this Project
Every line of HTML, CSS, and JavaScript, as well as the world-building content, was generated through AI prompts. The goal was to test the limits of AI-assisted web development and its ability to capture a specific thematic atmosphere.

## 🛠️ Tools Used
* **AI Model:** Claude (Anthropic)
* **Role:** AI Orchestrator / Prompt Engineer (Me)
* **Tech Stack:** HTML5, CSS3
